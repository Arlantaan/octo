Gmail
  1. Settings (gear) → See all settings
  2. General → Signature → Create new
  3. Paste, then Save changes at the bottom
Outlook
  1. Settings → Mail → Compose and reply
  2. New signature, give it a name
  3. Paste, then Save
Apple Mail
  1. Mail → Settings → Signatures
  2. Add (+), untick "Always match my default font"
  3. Paste into the signature box
